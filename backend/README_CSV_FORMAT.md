# Trip CSV Upload Format

## Sample CSV File

Use `sample_trips.csv` as a template for uploading trips.

## Required Columns

| Column | Required | Type | Description | Example |
|--------|----------|------|-------------|---------|
| `contract_id` | ✅ Yes | Integer | Contract ID | `1` |
| `client_id` | ✅ Yes | Integer | Client ID | `14` |
| `vendor_id` | ✅ Yes | Integer | Vendor ID | `18` |
| `start_time` | ✅ Yes | ISO DateTime | Trip start time | `2025-11-15T08:00:00` |
| `end_time` | ✅ Yes | ISO DateTime | Trip end time | `2025-11-15T08:45:00` |
| `distance_km` | ✅ Yes | Decimal | Distance in kilometers | `15.5` |
| `duration_min` | ✅ Yes | Integer | Duration in minutes | `40` |
| `employee_id` | ❌ No | Integer | Employee ID | `61` |
| `trip_type` | ❌ No | String | INBOUND/OUTBOUND/PICKUP/DROPOFF | `INBOUND` |
| `booking_time` | ❌ No | ISO DateTime | Scheduled booking time | `2025-11-15T08:00:00` |
| `vehicle_type` | ❌ No | String | Vehicle type | `SEDAN` |
| `vehicle_number` | ❌ No | String | Vehicle registration | `KA-12-AB-1234` |
| `currency` | ❌ No | String | Currency code | `INR` |

## Important Notes

1. **Date Format**: Use ISO 8601 format: `YYYY-MM-DDTHH:MM:SS`
   - Example: `2025-11-15T08:00:00`

2. **Contract/Client/Vendor IDs**: Must match existing records in database
   - Check your database or use the frontend to see available IDs

3. **Employee ID**: Must belong to the client specified in `client_id`

4. **Trip IDs**: Auto-generated by database (SERIAL) - don't include in CSV

5. **Validation**: 
   - Contract must exist
   - Client/Vendor IDs must match the contract
   - Employee must belong to the client
   - `end_time` must be after `start_time`

## Sample Row

```csv
contract_id,client_id,vendor_id,employee_id,trip_type,booking_time,start_time,end_time,distance_km,duration_min,vehicle_type,vehicle_number,currency
1,14,18,61,INBOUND,2025-11-15T08:00:00,2025-11-15T08:05:00,2025-11-15T08:45:00,15.5,40,SEDAN,KA-12-AB-1234,INR
```

## How to Use

1. Open `sample_trips.csv` in Excel/Google Sheets
2. Modify the data as needed
3. Make sure contract_id, client_id, vendor_id match your database
4. Save as CSV
5. Upload via frontend: Trips → Ingest CSV

## Current Database IDs (from your setup)

- **Clients**: 14, 15, 16
- **Vendors**: 18, 19, 20, 21
- **Employees**: 61-75 (approximately)
- **Contracts**: Check via frontend Contracts page
