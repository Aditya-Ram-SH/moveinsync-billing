Model 1: The "Package" Model (Fixed Monthly)
Best for: Managing costs with a fleet vendor. Logic: Client pays $50,000 flat. Vendor drives up to 5,000 km. If they drive 5,001km, they get an extra rate.

JSON
{
  "billing_cycle_months": 1,
  "monthly_fixed_pay": 50000.00,

  "limits": {
    "included_km": 5000,
    "included_trips": 500
  },

  "vendor_payouts": {
    "per_extra_km": 15.00,        // Performance Pay: Extra Distance
    "per_extra_trip": 200.00,     // Performance Pay: Extra Trips
    "night_shift_bonus": 100.00   // Performance Pay: Hardship
  },

  "employee_incentives": {
    "delay_threshold_min": 15,    // SLA Breach Rule
    "delay_compensation_amount": 50.00  // "Sorry for the delay" payout
  }
}

Model 2: The "Trip" Model (Pay-Per-Use)
Best for: On-demand cabs (like Uber/Ola integration). Logic: Pay a base fare + distance + time.

JSON
{
  "billing_cycle_months": 1,

  "rates": {
    "base_fare": 100.00,
    "per_km_rate": 12.00,
    "night_multiplier": 1.5       // Vendor Performance Pay
  },

  "employee_incentives": {
    "delay_threshold_min": 10,    // Stricter SLA for on-demand
    "delay_compensation_amount": 30.00,
  }
}

Model 3: Hybrid Variant A (Minimum Guarantee)
Best for: Retaining vendors who need safety. Logic: "We pay you per trip, but we guarantee you at least $30,000/month even if no one travels."
JSON
{
  "variant": "MIN_GUARANTEE",
  "billing_cycle_months": 1,

  "rates": {
    "per_km_rate": 14.00,
    "base_fare_per_trip": 50.00
  },

  "guarantee": {
    "monthly_min_payout": 30000.00
  },

  "employee_incentives": {
    "delay_threshold_min": 20,
    "delay_compensation_amount": 50.00
  }
}


Model 4: HYBRID B (Base Distance Tier)
The Logic: "We pay a flat ₹300 for every trip up to 15km. If you drive more than 15km, we pay extra per km."

Why it's Hybrid: It acts like a Fixed Package for short trips (predictable cost) but switches to a Trip Model for long trips.

Business Case: Great for standard office commutes where 90% of employees live within 15km.
JSON
{
  "variant": "BASE_DISTANCE_TIER",
  "billing_cycle_months": 1,

  "rates": {
    "fixed_base_pay": 300.00,       // You get this no matter what (even for 1km)
    "per_extra_km_rate": 18.00      // Charged ONLY for distance > included_km
  },

  "thresholds": {
    "included_km_per_trip": 15.0    // The "Free" tier inside the fixed pay
  },

  "employee_incentives": {
    "delay_threshold_min": 15,
    "delay_compensation_amount": 40.00
  }
}

Summary of the 4 Unlocked Models:
- PACKAGE: Fixed Monthly Salary + OT (Vendor Performance).
- TRIP: Standard Taxi Meter (Base + Time + Distance).
- HYBRID (Min Guarantee): Pay-per-km, but Vendor guaranteed ₹30k/month.
- HYBRID (Base Tier): Fixed Price per Trip (up to X km), then variable.

Since you prefer this (and it is cleaner), let’s move that TypeScript registry into Python.

Here is how to implement the "Backend Template API" in 5 minutes.
